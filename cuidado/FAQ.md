# Preguntas frecuentes

## ¿CuidadoWeb le indica al técnico o a la agencia cómo reparar un hackeo?

El informe les deja lo que CuidadoWeb vio y el límite de lo que no debe tocarse.

Puede incluir el nombre del archivo marcado como sospechoso, el plugin que tiene un parche conocido, la hora del incidente y tres herramientas para revisarlo: Wordfence, Sucuri y MalCare. También recuerda que se actualiza un solo plugin, con confirmación, y que no se edita el tema ni `functions.php`.

La reparación la hace el técnico o la agencia en el WordPress del cliente. CuidadoWeb no escribe los pasos para borrar el código infectado ni los ejecuta. Tampoco instala ni configura esas herramientas.

Hoy este aviso no está en el informe: el conector todavía no marca archivos sospechosos.
