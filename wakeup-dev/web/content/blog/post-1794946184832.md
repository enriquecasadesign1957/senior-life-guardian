## Configuring Grafana Webhooks
Grafana can send a raw JSON payload to any HTTP endpoint. By adding custom annotations or tags to an alert rule you can control which alerts should trigger a voice call. For example, only alerts tagged `critical` or `urgent` will be forwarded to WakeUp Dev.

## Sending to WakeUp Dev
When the webhook fires, the payload is transformed into the WakeUp Dev format and posted to `https://api.wakeupdev.com/v1/alert`. The API key is passed in the `x-api-key` header, and the body contains the alert message, severity, and any metadata needed for routing.

```bash
curl -X POST https://api.wakeupdev.com/v1/alert -H "x-api-key: YOUR_API_KEY" -H "Content-Type: application/json" -d '{"alert":"CPU > 80%","severity":"critical"}'
```

## Benefits
- **Reduced duplicate voice calls**: Only critical alerts trigger a call, preventing the same issue from ringing multiple on‑call members.
- **Cost control**: Unlimited seats mean every team member can be on‑call without extra per‑seat fees, and pay‑per‑alert keeps voice costs predictable.
- **Simplified escalation**: The webhook can include a `route` field that maps to a specific on‑call rotation, eliminating manual triage.
- **Lower alert fatigue**: Voice ACKs and digit‑1 acknowledgment reduce the need for multiple notification channels.
