# Dynamic Voice Escalation with Grafana Webhooks and WakeUp Dev

On‑call fatigue is a measurable cost. Every missed or ignored alert adds to downtime and developer burnout. WakeUp Dev solves this by turning a simple Grafana webhook into a voice‑first escalation that scales without per‑seat charges.

## Grafana Webhook Integration

Grafana’s alerting engine can POST a JSON payload to any URL when a rule fires. Instead of sending to PagerDuty or Opsgenie, point the webhook at WakeUp Dev’s `/v1/alert` endpoint. The payload is enriched with the alert name, severity, and a custom message, then wrapped in a minimal wrapper that WakeUp Dev expects.

```bash
curl -X POST https://api.wakeupdev.com/v1/alert \
  -H \"Content-Type: application/json\" \
  -H \"x-api-key: YOUR_API_KEY\" \
  -d '{\n  \"title\": \"High CPU on prod-db\",\n  \"description\": \"CPU usage > 90% for 5 minutes\",\n  \"severity\": \"critical\",\n  \"tags\": [\"database\", \"cpu\"]\n}'
```

WakeUp Dev parses the JSON, places the call on the first available seat, and plays a short prompt. The engineer can acknowledge with digit‑1; the call then hands off to the next escalation tier if needed.

## Building Dynamic Escalation Chains

Because WakeUp Dev seats are unlimited, you can create a tiered chain without worrying about seat limits. Define a list of phone numbers in your Grafana alert rule and use a simple script to iterate over them:

```json
{\n  \"recipients\": [\"+15551234567\", \"+15559876543\", \"+15557654321\"],\n  \"message\": \"Alert: {{alert.title}} – {{alert.severity}}\"\n}
```

When the first call is answered, the engineer can ACK with digit‑1. If no ACK is received within 30 seconds, WakeUp Dev automatically dials the next number in the list. This logic lives entirely in the webhook payload, so you avoid hard‑coding multiple webhook URLs.

### Benefits

- Zero per‑seat cost – Unlimited seats mean you can add new responders as your team grows.
- Reduced alert fatigue – Voice ACKs are less intrusive than SMS or email, and the 30‑second timeout prevents endless ringing.
- Cost‑effective – Pay only for the voice minutes you use, not for seats you don’t fill.
