## Integration with Grafana

Grafana can send alerts to any HTTP endpoint. Configure the webhook to point at WakeUp Dev's POST /v1/alert endpoint and include your x‑api‑key header.

## Integration with UptimeRobot

UptimeRobot also supports webhooks. Use the same endpoint and key so both services funnel into the same on‑call stream.

## Unified Routing and Cost Savings

By routing both Grafana and UptimeRobot alerts through WakeUp Dev you:
- eliminate per‑seat billing – seats are unlimited
- reduce alert fatigue with a single voice ACK workflow
- keep all alert metadata in one place for audit and analysis

## Example POST /v1/alert

```bash
curl -X POST https://api.wakeupdev.com/v1/alert \
  -H \"x-api-key: YOUR_API_KEY\" \
  -H \"Content-Type: application/json\" \
  -d '{
  \"source\": \"grafana\",
  \"severity\": \"critical\",
  \"title\": \"CPU usage > 90%\",
  \"message\": \"Instance i-1234 is over 90% CPU.\",
  \"tags\": [\"cpu\", \"production\"]
}'
```

The response will trigger a voice cascade to the on‑call roster. The first person to press 1 acknowledges the alert, ending the call for the rest.
